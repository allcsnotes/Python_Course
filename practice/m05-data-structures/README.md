# Module 5 practice sheet: 25 data structure exercises

25 small exercises for Module 5 (lists, tuples, dictionaries, sets, comprehensions, names and mutability). Do these after the lessons M05-L01 to M05-L06 and the build [M05-B02](../../m05-data-structures/m05-b02-build-an-expense-tracker/), and before you move on.

## How to use this sheet

1. Open [sheet.md](sheet.md). Each exercise is a short task about allcsvideos.com and its cast (Asha, Lukas, Priya, Meera and Rahul).
2. **Try first.** Write each program yourself in its own file, `Ex01.py`, `Ex02.py` and so on, before you look at any answer. Some exercises ask you to predict the output (guess on paper, then run), some ask you to fix broken code, and some ask you to build something small.
3. **Then check.** Every exercise in the sheet has a hint, an explanation, a full solution and the real output. Open the hint first, and only then the solution.
4. The same solutions are also in the [solutions/](solutions/) folder as ready-to-run files. Use them to compare with your own file, or to see the output on your machine.

## Before you start

- Python 3.14 or newer. Check with `python --version` (on Mac or Linux the command may be `python3`).
- No packages to install. None of the exercises read from the keyboard, from files or from the internet.

## Run a solution

From the root of this repository:

```bash
cd practice/m05-data-structures/solutions
python Ex01.py
```

Replace `Ex01.py` with any file from `Ex01.py` to `Ex25.py`. The output should match the "Real output" shown in the sheet. A few solutions print `sorted(...)` of a set, because Python does not promise an order inside a set.
