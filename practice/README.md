# Practice sheets

Four practice sheets that come after certain modules. Each one gives you exercises, a hint, and a worked answer with the real output. Try each exercise yourself before you open its answer.

You need Python 3.14 or newer (Docker for a few questions on the final sheet, as the sheet says).

| Sheet | Do it after | What it covers | Its files |
|---|---|---|---|
| [M02 sheet](m02-variables-and-data-types/README.md): 20 exercises | Module 2, [M02-L05](../m02-variables-and-data-types/m02-l05-input-and-output/) | Variables, numbers, text, True/False/None, input and output | [solutions](m02-variables-and-data-types/solutions/) |
| [M05 sheet](m05-data-structures/README.md): 25 exercises | Module 5, [M05-L06](../m05-data-structures/m05-l06-names-objects-and-mutability/) | Lists, tuples, dicts, sets, comprehensions, mutability | [solutions](m05-data-structures/solutions/) |
| [M08 sheet](m08-object-oriented-programming/README.md) | Module 8, [M08-L06](../m08-object-oriented-programming/m08-l06-dataclasses-enums-and-abstract-classes/) | Classes, properties, inheritance, dunder methods, dataclasses | [solutions](m08-object-oriented-programming/solutions/) |
| [M23 final sheet](m23-interviews-and-capstone/README.md) | The whole course, [M23-B16](../m23-interviews-and-capstone/m23-b16-capstone-course-copilot-lite/) | Interview questions, gotchas, backend and testing tasks | [solutions](m23-interviews-and-capstone/solutions/) |
