# allcsv-cli

Look at allcsvideos data from the command line.

```console
$ allcsv courses list --level beginner
$ allcsv enrollments report --from 2026-09-01
$ allcsv logs analyse server.log
```

Every command prints a table, or JSON with `--json`.

## Install

```console
$ uv tool install allcsv-cli
```
